# First ROM Test Scope

The first ROM test should boot a base ROM before Aelita integration. After the base ROM is validated, test Aelita as a preloaded or system app.

## Hardware smoke

- boot
- touch
- display
- Wi-Fi
- SIM/mobile network
- audio
- camera open
- charging
- USB
- sleep/wake
- Bluetooth
- fingerprint if present

## Aelita smoke

- Shell opens
- HOME launcher
- status
- memory
- projects
- journal
- apps
- Permission Center
